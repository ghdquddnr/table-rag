## 결론

한국어 IR·재무 PDF는 내장 폰트 인코딩으로 인해 경량 파서(MarkItDown)가  
CID 코드를 그대로 출력하는 경우가 빈번하다.

Docling은 **TableFormer 딥러닝 모델**로 표 구조를 시각적으로 인식하므로  
폰트 인코딩에 무관하게 셀 경계와 수치 데이터를 보존한다.

| 기준 | Docling | MarkItDown |
|------|---------|------------|
| 표 구조 인식 방식 | TableFormer (딥러닝, 이미지 기반) | pdfminer (폰트 텍스트 추출) |
| 한국어 내장폰트 PDF | ✅ 수치 보존 | ❌ CID 코드 출력 |
| 파싱 속도 | 느림 (~2분/문서) | 빠름 (~8초/문서) |
| RAG 활용 가능성 | ✅ | ❌ |

**이 프로젝트의 선택 근거**: 검색 품질 증명이 목표이므로 파싱 속도보다  
수치 데이터 보존이 우선. 문서 인제스트는 1회성 작업이므로 속도 패널티 수용 가능.
